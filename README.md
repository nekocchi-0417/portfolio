# Zhang Yue’s personal website

A static personal website about AI governance, research, writing, and a few side quests, with the earlier design portfolio preserved as an archive.

- **Text and links:** edit `index.html`.
- **Layout and styles:** edit `personal.css`.
- **Interactions:** edit `personal.js`.
- **Images and fonts:** use the files in `assets/`. The six local images are shared with the archive About page; remaining archive images still use their original UXfolio URLs.
- **Earlier design work:** edit `design.html`, `about.html`, `skills.html`, or `projects/`; these pages use `style.css` and `script.js`.

No build or package installation is needed. Open `index.html` directly, or run a local static server from this folder:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

The existing GitHub Pages site deploys from the `main` branch and repository root. Push changes to `main` to update [the live site](https://nekocchi-0417.github.io/portfolio/). Check the personal home and archive on desktop and mobile before publishing.
